# C6 Application Factory

The Application Factory begins only after Opportunity Intelligence and produces a traceable, evidence-backed application package.

Lifecycle:
QUALIFIED -> PLANNED -> DRAFTED -> REVIEWED -> ATS_VERIFIED -> READY_FOR_USER_SUBMISSION -> SUBMITTED -> OUTCOME_CAPTURED

The factory records the exact opportunity, assessment snapshot, evidence map, artifact versions, and submission metadata.

## Evidence rule
Candidate claims must originate in the private profile/evidence set. Missing requirements remain explicit gaps. The system must never manufacture employment, achievements, qualifications, technologies, metrics, or responsibilities.

## Artifact contract
- CV: tailored to the posting using verified candidate evidence.
- Cover letter: role/company-specific claims must be supported by the captured posting and independently verified company research where applicable.
- ATS check: machine-readable text/structure and requirement coverage checks.
- Final pack: immutable set of artifact versions presented for human review.

## Human gate
The system may prepare everything, but **the user remains the submitter**. No automatic application submission or automatic email is part of this contract.

## Arsenal reuse
The existing job-application-assistant skills remain the content-generation source of truth: candidate profile, writing style, job evaluation, CV templates, cover-letter templates, application forms, web research, and interview prep. The new engine stores orchestration/state; it does not duplicate those templates.

## Winner Effect
Target Win: submit an evidence-backed application.
Proof: exact artifact versions plus submission confirmation.
Next Win: capture interview/outcome evidence after submission.
